# Участие в разработке

Спасибо за интерес к проекту! Ниже — короткая памятка для контрибьюторов.

## Окружение

- Python >= 3.8.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
```

## Перед отправкой Pull Request

Убедитесь, что проходят проверки:

```bash
pytest             # тесты
ruff check .       # линтер
mypy avito_ads     # проверка типов (strict)
```

## Соглашения по коду

- Идентификаторы (классы, функции, переменные) — на английском языке.
- Docstrings и пользовательская документация — на русском языке.
- Поддерживаем совместимость с Python 3.8: не используем синтаксис 3.9+/3.10+
  (`list[...]`, `X | None` в рантайме и т. п.). Аннотации типов — через
  `typing.List`, `typing.Optional` и `from __future__ import annotations`.
- Новый код покрывайте тестами; HTTP мокируйте через `httpx.MockTransport` (см. `tests/conftest.py`); тесты пишите параметризованными для sync и async.

## Сообщения об ошибках

Опишите шаги воспроизведения, версию Python и ожидаемое поведение. Не прикладывайте
реальные `client_secret` и токены.
